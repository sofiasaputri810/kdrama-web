📐 Metrik Evaluasi Utama
RMSE & MAE
RMSE
Root Mean Square Error

Mengukur akar kuadrat dari rata-rata kuadrat selisih antara nilai prediksi dan rating aktual. RMSE memberikan penalti lebih besar untuk error yang besar.

RMSE = √( Σ(rui - r̂ui)² / n )
Interpretasi: Semakin rendah = Semakin akurat. Nilai 0 = prediksi sempurna.
MAE
Mean Absolute Error

Mengukur rata-rata selisih absolut antara prediksi dan nilai sebenarnya. MAE memberikan bobot yang sama rata untuk setiap kesalahan — lebih stabil terhadap outlier.

MAE = Σ|rui - r̂ui| / n
Interpretasi: Semakin rendah = Semakin akurat. Nilai 0 = prediksi sempurna.

CBF + Item Rating Augmentation

CBF murni dengan augmentasi item rating metadata (kolom rating_y dari dataset). Tidak menggunakan data rating pengguna saat training — hanya atribut item. Prediksi menggunakan Weighted Sum yang sama dengan CF → perbandingan apple-to-apple.

Konten (70%) Genre (×3), Cast (×2), Tags (×2), Synopsis, Director — TF-IDF
Item Rating (30%) rating_y dari dataset (atribut item, bukan dari user) — MinMaxScaler
Prediksi Weighted Sum — identik dengan CF → Apple-to-Apple, tetap Pure CBF
🤝
Item-Based CF

Merekomendasikan berdasarkan pola rating pengguna menggunakan Item-Based CF dengan mean-centering dan prediksi Weighted Sum.

Input Matriks User-Item dari data rating
Similarity Cosine Similarity antar kolom item
Prediksi Weighted Sum (Sarwar et al., 2001)
